What's in this little demo

Fluid type & spacing

Headings scale smoothly between a minimum and maximum size using clamp(), instead of jumping between fixed sizes at breakpoints.

Design tokens, not magic numbers

Every color, radius and shadow lives once as a CSS custom property on :root, so the whole page's look can change from a handful of variables.

A real, accessible nav toggle

The mobile menu button updates aria-expanded, is reachable and operable by keyboard, and the menu itself is a real, focusable list — not a div soup.

Respects reduced motion

The subtle entrance animation on these cards is skipped entirely for anyone whose system has prefers-reduced-motion turned on.
